Reports SkyTemplate call sites whose argument count does not match the resolved PHP function / method signature.
  • Required parameter missing — the callee declares a parameter with no default value, but the call passes nothing (or only later named args) to fill it. 
    function helper(string $a) {}
{=helper()}                    {* missing $a *}
  • Too many arguments — the call passes more positional values than the callee declares, and the callee is not variadic. 
    function f($a, $b) {}
{=f(1, 2, 3)}                  {* third argument has no parameter *}

Variadic callees (function many(...$xs) {}) are exempt from the “too many” check — any positional count is accepted.

Default-value parameters are exempt from the “required missing” check.

Severity: WARNING. PHP allows runtime-registered functions, custom autoloaders, and framework magic, so a static signature mismatch isn't always a defect. The inspection prefers warning over error to avoid false alarms.

Multiple resolutions. When a name resolves to several PHP candidates (e.g. via useClass aliasing or simple-name fallback across namespaces), the inspection picks the most permissive signature: the candidate with the lowest required count for “missing” checks, and any candidate with sufficient parameters / variadic for the “too many” check.

Call shapes covered:

  • Paren calls: {=foo(a, b)}, {?foo(a)}, {if foo(a)}
  • Static methods: {=Cls::method(a, b)}
  • Pipe filters: {var|func=a, b}, {var|sprintf='%05d', ##}

Object method calls ({=user.method(...)}) require variable type inference and are out of scope.

Honours the master Enable SkyTemplate support toggle.
