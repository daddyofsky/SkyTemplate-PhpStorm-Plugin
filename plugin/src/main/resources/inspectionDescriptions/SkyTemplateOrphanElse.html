Reports SkyTemplate {else} / {elseif …} / {:} / {:expr} branch tags that appear outside any enclosing {if} / {loop} block.

The SkyTemplate compiler cannot place such a branch and would fail at compile time.

Example that triggers:

{else}
  fallback content
{/}

Runs in dedicated SkyTemplate files (*.sky) and in HTML host files where SkyTemplate constructs are embedded.
