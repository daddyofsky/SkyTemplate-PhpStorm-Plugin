Reports SkyTemplate loop-scope variables that request a parent-loop depth deeper than the actual nesting at the variable's position.

The number of leading dots and the optional @N modifier on a SkyTemplate variable name select the loop frame to read from. When the requested depth exceeds the surrounding nesting, the compiler clamps to depth 0 and reads from $v0[…] / $i0 — undefined data at runtime.

Mirrors the SkyTemplate compiler's parseLoopVar / parseReservedVar formula up = max(@N, leading_dots − 1).

Examples that trigger:

{.var}                       {* outside any loop *}
{loop xs}{..var}{/}          {* requesting parent inside one loop *}
{loop xs}{.var@2}{/}         {* @N exceeds nesting *}
{_index}                     {* reserved var outside loop *}
{loop xs}{_index@1}{/}       {* @N exceeds for reserved var *}

The {.var@} shorthand (bare @) is treated as @1; this inspection accepts it inside one or more loops and flags it only when no loop is nested.

Runs in *.sky files (this inspection) and in HTML host files (via the companion annotator). Honours the master Enable SkyTemplate support toggle.
