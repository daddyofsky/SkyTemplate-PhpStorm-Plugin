Reports a second {else} / {:} / {:cond} / {elseif …} branch in the same {if} / {loop} / {foreach} / {for} / {while} block once a bare {else} / {:} has already terminated the chain.

The SkyTemplate compiler keeps emitting branches in source order and produces invalid PHP of the shape } else { … } else { … } — a syntax error that surfaces only at render time. Catching it statically avoids a runtime trap.

Example that triggers:

{?cond}
  primary content
{:}
  fallback content
{else}                {* duplicate — compiler error at render *}
  another fallback
{/}

The same rule applies to a {:} empty-branch on a {loop} / {foreach} / {for} / {while} followed by another {:}.

Runs in *.sky files (this inspection) and in HTML host files (via the companion annotator). Honours the master Enable SkyTemplate support toggle.
