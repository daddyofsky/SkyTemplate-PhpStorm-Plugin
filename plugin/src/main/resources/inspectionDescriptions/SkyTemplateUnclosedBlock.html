Reports SkyTemplate block tags that are opened but never closed.

Triggers on tags such as {loop …}, {if …}, {foreach …}, {?expr}, {?:expr} (elvis fallback), {@…}, {%…}, {each …}, {for …}, {while …} when no matching {/} or {end} closer is found before end-of-file.

Example that triggers:

{loop xs as x}
  <li>{x}</li>
<!-- end of file, no {/} -->

The error message also includes a likely close near line N hint based on indentation — the line one below the deepest body line of the opener — to help locate where the closer was probably intended.

Runs in dedicated SkyTemplate files (*.sky) and in HTML host files where SkyTemplate constructs are embedded. Orphan close tags ({/} / {end} with no opener) are not reported — partial-template fragments where the opener lives in another included file are legitimate.
